## 0. 对 ChatGPT 对话要点的取舍(先看这个)

对话来源:`~/Downloads/chatgpt_new_chat_2026-10-12 (4).md`(前半是 ESP32 硬件讨论,后半是口述 + 博客初稿,初稿在文件里重复粘贴了 3 遍)。

| 要点 | 处理 | 理由 |
|---|---|---|
| 动机:瓶颈在人,AI 在待命而人在睡觉;"小弟一直等你派活" | **采用(改写)** | 做开场钩子。但按对话自己的建议,不说"瓶颈就是人",说"瓶颈之一是我没给它持续的输入" |
| 减少摩擦、"系统顺应人性而不是对抗人性"、字节类比 | **采用** | 这是产品存在的理由:iPhone 语音备忘录能用但不好用,启动有摩擦 |
| 一个反直觉问题开场("AI 为什么还在等人") | **采用** | 开头 15 秒 |
| 任何时候想说话就说话 + 环境音全捕捉 | **采用** | 对应 Ambient 模式 + Quick 按住说话 |
| 隐私边界(录音状态、可停止、对他人尊重) | **采用并强化** | 对应 iOS 橙点、本地 ASR、数据只在自己 Mac。拍摄时不要录到他人声音 |
| Context engineering / 每天帮我整理、to-do | **部分采用** | 真实存在的:daily digest、quick 路由(待办/记一下/问 Claude)。只演示这些 |
| "它帮我梳理出一个值得深入的项目""跨时间关联发现 aha" | **不用作既成事实,放结尾 roadmap** | 当前 digest 只是时间线 + 可选的 AI 派生段落,没有跨天关联/自动更新知识库。ChatGPT 自己也提醒"没有结果就当实验目标" |
| "24 小时捕捉,连梦话都录下来了" | **不用** | 无证据;且实测 App 在来电/Siri 打断后后台常无法自动恢复(见 ios/README),不能说 24h 不漏。除非你另有录音可展示 |
| ESP32 + microSD 嵌入式录音器、先存卡再导入 | **拒绝** | 没做。真实方案是 iPhone App。可在结尾 roadmap 一句带过,或完全不提 |
| 5–8 分钟视频 / 三期系列 | **改为** | 本次做 2–3 分钟主片 + 30–45 秒短版;"第二期搭建、第三期一个月结果"可作片尾预告,但要等真有数据 |
| "数据全私有、不上云" | **需要精确措辞** | 录音和 ASR 全在本机。但 `daily_digest --llm` 和"问 Claude"会把**转写文字**交给 `claude -p`(云端模型)。视频只说"录音和语音识别不出本机",不要说"一切都不上云" |
| 5 点之外的小坑 | 注意 | 免费签名 7 天过期;v1 没接 Tailscale,所以只在同一 Wi-Fi 实时上传,离网排队;网页端录音只能 localhost |

**不要在视频里声称的东西**:跨日关联洞察、自动更新知识库、全天不丢片、梦话、硬件录音器、Tailscale 外网同步、Qwen3-ASR(未测)。

## 1. 受众与核心信息

**主受众**:会做点东西的技术人 / AI 重度用户(开发者、SRE、做个人知识库的人),看过 Claude Code 之类工具,对"个人 AI 工作流"有兴趣。次受众:想要低摩擦记录想法的普通人(用画面而非术语讲)。

**一句话核心信息**:
> 想法最容易丢在"掏出手机、打开 App、开始记"的那几秒里,所以我做了一个把这几秒去掉的东西:放口袋里,说话就行,剩下的全在我自己的 Mac 上完成。

## 2. 时长与版本

- 主片 **2:45 左右**(上限 3:00)
- 短版 **40 秒**(竖屏/横屏皆可,只保留:钩子 → 锁屏录音 → Mac 出文字 → 说"待办"落进清单 → 一句 CTA)
- 可选:5 分钟"技术向"加长版 = 主片 + 噪声过滤 + 搭建故事各展开 40 秒(不是本次目标)

## 6. 拍摄前必须确认(别拍了才发现)

1. 真机是否能稳定出完整链路(手机→Mac 有转写);首次拍前先跑一次 `ops/aha doctor`。
2. `com.aha.dispatch` 已加载(每 2 分钟分发一次 quick 语音);拍前 `launchctl list | grep aha` 确认一下。未加载的是 `com.aha.digest`。
3. "问 Claude" 需要 `claude` CLI 可用,先单独试一次,答案文件要真的生成。
4. 镜头 17、18 使用已有素材或截图,不需要重做。
5. 说"一天搭完"之前核对 git log 与 PLAN 日期(PLAN 里的实测日期是 2026-10-09),口径用"几天内"最稳。
