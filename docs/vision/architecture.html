AHA MOMENT × CONTEXT INFRASTRUCTURE

从一句随口的话，到一个懂我的 AI

入口是一个只有一个按钮的录音器。说出来的话被模型转成文字，一天一天堆起来；这些文字再和 context infrastructure 里「我是谁、我怎么想、我在做什么」放在一起交给 LLM，帮我把每天的所思所想、做过的事整理清楚，并找出它们之间我自己没注意到的关联。

01入口：录音

Aha 录音器已实现

iPhone 一个按钮：点一下开始，再点一下停止。锁屏照录，录几句还是录一天由我决定。

不丢、不打扰已实现

60 秒自动切段，App 被杀也能救回；停了会通知；不联网也能录，回家自动上传。

02LLM 转写

本地模型已实现

Mac 上的 Whisper large-v3-turbo，约 10 倍实时；声音不出这台电脑；没人说话的噪音自动过滤。

远端模型可选

出门在外、或想要更强的识别时，换成云端模型；接口已经留好，换后端不动上下游。

03文字

一段录音 = 一个文件已实现

只有文字，放进 daily_records/日期_时间_aha.md，转完几秒就出现，随手可复制。

按天、按月堆起来已实现

原始音频永远保留，换了更好的模型可以把过去全部重转一遍。

04LLM × 我的上下文

带着「我是谁」去读方向

一天 / 一周 / 一个月的文字，连同 context infrastructure 里的画像、公理、项目、记忆一起交给 LLM。

上下文底座已存在

规则、skills、三层记忆、每日 observer，下面单独展开。

05产出

每天的所思所想方向

把零散的话整理成：今天在想什么、卡在哪、有什么新念头。

每天干了什么方向

从口述里拎出做过的事、待办、决定，接上工作日志。

跨时间的关联最想要

三周前随口一句和今天的问题其实是一件事——这是 AI 最该做、我自己最做不到的。

产出再写回 context infrastructure（记忆、观察、项目笔记），下一次 LLM 读到的「我」就更完整——这是一个越用越准的闭环。

文字是怎么堆起来的

单条文字没什么价值，价值在时间维度上的密度。

一段录音一个文件，一句到一小时
→
一天几个到几十个文件
→
一个月上千段，自己读不完，正好交给 LLM

Context Infrastructure 最重要的能力

一个放在 git 里的个人 AI 工作区。每次开一个新的 AI 会话，它先读这里，所以 AI 一上来就知道我是谁、我在乎什么、东西放在哪、事情该怎么做。

核心：三层记忆
让 AI 记得我，而且记得越来越准
L3 · 全局约束rules/ 下的身份、画像、沟通方式、公理、skills。每次会话被动加载。
L1/L2 · 动态记忆contexts/memory/OBSERVATIONS.md，按日期记录 🔴🟡🟢 观察，需要时主动检索。
自动积累每天 observer 扫新增内容写观察，每周 reflector 把反复出现的观察升级成规则或清理掉。
我是谁
身份与画像

SOUL.md 定义 AI 的角色和底线；USER.md 记录我的背景、方向、偏好、讨厌什么；COMMUNICATION.md 规定怎么跟我说话。

我怎么想
52 条决策公理

从自己经历里提炼的判断原则，带触发词和案例。遇到取舍时 AI 拿它们当思考的起点，而不是给通用建议。

事情怎么做
约 70 个 skills

可复用的做事方法：深度调研、并行 subagent、SRE 排障、博客发布、日语 Anki、语义搜索……「怎么做 X」先查 skill。

东西在哪
文件路由表

WORKSPACE.md 是整个工作区的目录索引：每类内容放哪、去哪找，AI 不用全盘搜索。

我的知识库
原始记录 + 加工过的知识
  • daily_records/ 每日原始记录（宁原始勿提炼，Aha 的文字也在这）
  • survey_sessions/ 调研报告
  • thought_review/ 复盘与方法论
  • projects/ 长期项目，各自独立 repo
自己会动
定时任务 + 多 agent
  • 每天：observer 写观察、Aha 文字同步进 daily_records
  • 每周：reflector 整理记忆、晋升规则
  • 大任务拆给并行 subagent，按任务类型路由到不同模型
为什么两者要接在一起：context infrastructure 知道「我是谁」，但它只能看到我写下来的东西；Aha 把我没来得及写、随口说出来的那部分补进来。一个提供长期的我，一个提供每天的我，LLM 站在两者中间，才有可能发现「三周前那句话」和「今天这个问题」之间的联系。
